25. Связь через программный канал
Напишите программу, которая создает подпроцесс, взаимодействующий с родителем через программный канал. Один из процессов выдает в канал текст, состоящий из символов верхнего и нижнего регистров. Второй процесс переводит все символы в верхний регистр, и выводит полученный текст на терминал. Подсказка: см. toupper(3).

# 25: Связь через программный канал (pipe)

## 1. Подготовка рабочего места
Переходим в директорию задания и создаем новую папку:

cd ~/MyOSTest
mkdir task_25
cd task_25

## 2. Ключевые концепции для понимания задачи

• Программный канал (pipe): Временный буфер в ядре, позволяющий двум родственным процессам обмениваться данными. Работает по принципу FIFO (First In, First Out) и является однонаправленным.
• Наследование дескрипторов: После вызова `fork()` оба процесса (родитель и потомок) получают копии файловых дескрипторов канала. Это и позволяет им общаться.
• Правило закрытия концов: Критически важно закрывать неиспользуемые концы канала в каждом процессе. Если потомок не закроет конец записи, системный вызов `read` никогда не вернет EOF (0), и процесс зависнет в ожидании.
• Безопасность toupper: Аргумент функции `toupper` всегда нужно явно приводить к `unsigned char`, чтобы избежать неопределенного поведения при обработке символов с кодами > 127 (например, кириллицы).

## 3. Шпаргалка: Программные каналы (Pipes)

СИСТЕМНЫЕ ВЫЗОВЫ (unistd.h)
• int pipe(int pipefd[2]): 
  Создаёт неименованный канал. 
  - pipefd[0] — файловый дескриптор для чтения (read end).
  - pipefd[1] — файловый дескриптор для записи (write end).
  Возвращает 0 при успехе, -1 при ошибке.

• ssize_t read(int fd, void *buf, size_t count): 
  Читает до count байт. Возвращает: >0 (количество байт), 0 (EOF, конец файла), -1 (ошибка).

• ssize_t write(int fd, const void *buf, size_t count): 
  Записывает count байт. Возвращает количество записанных байт или -1 при ошибке.

• int close(int fd): Закрывает файловый дескриптор. Освобождает ресурсы и влияет на генерацию EOF.

УПРАВЛЕНИЕ ПРОЦЕССАМИ
• pid_t fork(void): Создаёт дочерний процесс. Возвращает 0 в потомке, PID потомка в родителе, -1 при ошибке.
• pid_t wait(int *status): Приостанавливает родителя до завершения любого дочернего процесса (предотвращает появление "зомби").

ОБРАБОТКА СИМВОЛОВ (ctype.h)
• int toupper(int c): Преобразует строчную букву в прописную. 

ВАЖНО
• Канал строго однонаправленный: данные идут только от pipefd[1] к pipefd[0].
• `read` возвращает 0 (EOF) только тогда, когда **все** открытые в системе дескрипторы записи в этот канал закрыты.
• Буфер канала имеет ограниченный размер (обычно 64 КБ в Linux). Если буфер заполнен, вызов `write` блокируется до освобождения места.

## 4. Основные библиотеки

#include <stdio.h>        // printf, perror, fflush
#include <stdlib.h>       // exit, EXIT_SUCCESS
#include <unistd.h>       // pipe, fork, read, write, close
#include <string.h>       // strlen, strcspn
#include <ctype.h>        // toupper
#include <sys/wait.h>     // wait

## 5. Алгоритм решения

1. Создание канала:
   - Объявите массив `int pipefd[2]`.
   - Вызовите `pipe(pipefd)` и проверьте результат на ошибку.

2. Разделение процессов:
   - Вызовите `pid = fork()`. Обработайте случай ошибки (`pid == -1`).

3. Логика дочернего процесса (`pid == 0`):
   - Закройте ненужный конец записи: `close(pipefd[1])`.
   - Организуйте цикл `while`, в котором читаете данные из `pipefd[0]` с помощью `read`.
   - Если `read` вернул 0 (EOF), прервите цикл.
   - Пройдите по прочитанному буферу циклом `for` и примените `toupper((unsigned char)buffer[i])` к каждому символу.
   - Выведите преобразованную строку через `printf` и сделайте `fflush(stdout)`.
   - После цикла закройте `pipefd[0]` и завершите процесс через `exit(EXIT_SUCCESS)`.

4. Логика родительского процесса (`pid > 0`):
   - Закройте ненужный конец чтения: `close(pipefd[0])`.
   - Организуйте цикл для чтения ввода с клавиатуры (например, через `fgets`).
   - Если введен EOF (Ctrl+D) или пустая строка, прервите цикл.
   - Отправьте введенную строку (и дополнительно символ `\n` для переноса) в канал через `write(pipefd[1], ...)`.
   - После выхода из цикла закройте конец записи: `close(pipefd[1])`. Это отправит сигнал EOF потомку.
   - Вызовите `wait(NULL)`, чтобы дождаться корректного завершения дочернего процесса.

## 6. Сборка и тестирование

Создайте Makefile для сборки pipe_upper.c:

CC = gcc
CFLAGS = -O2
TARGET = pipe_upper
SRC = pipe_upper.c

all: $(TARGET)

$(TARGET): $(SRC)
	$(CC) $(CFLAGS) -o $(TARGET) $(SRC)

clean:
	rm -f $(TARGET)

.PHONY: all clean

Команды для запуска:
make clean
make
./pipe_upper
