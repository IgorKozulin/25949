Напишите программу - аналог команды ls -ld. Для каждого своего аргумента эта команда должна распечатывать:
●	Биты состояния файла в воспринимаемой человеком форме:
○	d если файл является каталогом
○	- если файл является обычным файлом
○	? во всех остальных случаях
●	Три группы символов, соответствующие правам доступа для хозяина, группы и всех остальных:
○	r если файл доступен для чтения, иначе -
○	w если файл доступен для записи, иначе -
○	x если файл доступен для исполнения, иначе -
●	Количество связей файла
○	Имена собственника и группы файла (совет - используйте getpwuid и getgrgid).
○	Если файл является обычным файлом, его размер. Иначе оставьте это поле пустым.
○	Дату модификации файла (используйте mtime).
○	Имя файла (если было задано имя с путем, нужно распечатать только имя).
 
Желательно, чтобы поля имели постоянную ширину, т.е. чтобы листинг имел вид таблицы.

# 18: Листинг каталога (ls -ld)

## 1. Подготовка рабочего места
Переходим в директорию задания и создаем новую папку:

cd ~/MyOSTest
mkdir task_18
cd task_18

## 2. Ключевые концепции для понимания задачи

• Метаданные файла: Вся необходимая информация (права, размер, владелец, время) хранится в структуре `stat`. Мы получаем её через системный вызов `lstat`.
• Преобразование ID в имена: В файловой системе хранятся числовые идентификаторы (UID/GID). Для вывода понятных имен нужно обращаться к системным базам данных через функции `getpwuid` и `getgrgid`.
• Обработка путей: Пользователь может передать полный путь (например, `/var/log/syslog`). Нам нужно вывести только имя файла (`syslog`). Для этого используется функция `basename`.
• Табличный вывод: Чтобы столбцы стояли ровно, как в настоящем `ls`, необходимо использовать спецификаторы ширины в `printf` (например, `%-8s` для выравнивания по левому краю).

## 3. Шпаргалка: Статистика файла и пользователи

СТРУКТУРЫ И ФУНКЦИИ
• struct stat: Основная структура метаданных.
  - st_mode: Тип файла и биты прав доступа.
  - st_nlink: Количество жестких ссылок.
  - st_uid / st_gid: Числовые ID владельца и группы.
  - st_size: Размер в байтах.
  - st_mtime: Время последней модификации (time_t).

• int lstat(const char *path, struct stat *buf):
  Заполняет структуру buf данными о файле path. 
  ВАЖНО: Если path — символическая ссылка, lstat возвращает данные самой ссылки, а не целевого файла (в отличие от stat).

• struct passwd *getpwuid(uid_t uid):
  Возвращает указатель на структуру пользователя.
  - pw_name: Имя пользователя (строка).
  - pw_uid: Числовой UID.

• struct group *getgrgid(gid_t gid):
  Возвращает указатель на структуру группы.
  - gr_name: Имя группы (строка).
  - gr_gid: Числовой GID.

• time.h функции:
  - struct tm *localtime(const time_t *timer): Преобразует время в локальное.
  - size_t strftime(char *s, size_t max, const char *format, const struct tm *tm): Форматирует дату в строку.

МАКРОСЫ ПРАВ ДОСТУПА (проверка через побитовое И &)
• Типы файлов:
  S_ISDIR(mode)  — каталог
  S_ISREG(mode)  — обычный файл
  S_ISLNK(mode)  — символическая ссылка

• Биты прав (Owner / Group / Others):
  S_IRUSR, S_IWUSR, S_IXUSR — чтение, запись, исполнение владельцем.
  S_IRGRP, S_IWGRP, S_IXGRP — чтение, запись, исполнение группой.
  S_IROTH, S_IWOTH, S_IXOTH — чтение, запись, исполнение остальными.

ФОРМАТИРОВАНИЕ ВЫВОДА (printf)
• %-10s : Строка, выровненная по левому краю, ширина 10 символов.
• %4ld  : Число (long), выровненное по правому краю, ширина 4 символа.
• %8lld : Число (long long), выровненное по правому краю, ширина 8 символов.

ВАЖНО
• Дата должна менять формат: если файл старше 6 месяцев, показываем год ("%b %e %Y"), иначе — время ("%b %e %H:%M").
• basename() извлекает имя файла из пути. Требует #include <libgen.h>.

## 4. Основные библиотеки

#include <stdio.h>        // printf, fprintf
#include <stdlib.h>       // exit
#include <sys/stat.h>     // lstat, struct stat, макросы прав
#include <unistd.h>       // стандартные вызовы

## 5. Алгоритм решения

1. Проверка аргументов:
   - Убедитесь, что передано хотя бы одно имя файла/каталога.

2. Цикл по аргументам:
   - Для каждого пути вызовите `lstat(argv[i], &st)`.
   - Если ошибка (возврат -1), выведите сообщение через `perror` и перейдите к следующему файлу.

3. Формирование строки прав доступа:
   - Напишите функцию, которая проверяет тип файла (d, -, l, ?) и биты прав (rwx) для владельца, группы и остальных.
   - Используйте побитовое И (&) с макросами S_IRUSR, S_IWUSR и т.д.

4. Получение имен владельца и группы:
   - Вызовите `getpwuid(st.st_uid)` и `getgrgid(st.st_gid)`.
   - Обработайте случай, когда функция вернет NULL (выведите "?").

5. Форматирование даты:
   - Сравните текущее время и время модификации файла (st.st_mtime).
   - Если разница больше 6 месяцев, используйте формат "%b %e %Y".
   - Иначе используйте формат "%b %e %H:%M".

6. Вывод строки (printf):
   - Права доступа (10 символов).
   - Количество ссылок (st.st_nlink).
   - Имя владельца (выравнивание по левому краю, ширина ~8).
   - Имя группы (выравнивание по левому краю, ширина ~8).
   - Размер файла (st.st_size, выравнивание по правому краю).
   - Дата модификации.
   - Имя файла (используйте `basename` для удаления пути).

## 6. Сборка и тестирование

Создайте Makefile для сборки my_ls.c:

CC = gcc
CFLAGS = -O2
TARGET = my_ls
SRC = my_ls.c

all: $(TARGET)

$(TARGET): $(SRC)
	$(CC) $(CFLAGS) -o $(TARGET) $(SRC)

clean:
	rm -f $(TARGET)

.PHONY: all clean

Команды для запуска:
make clean
make
./my_ls /etc/passwd /usr/bin/gcc /tmp /dev/null

## 7. Пример проверки

Ожидаемый вывод (примерный):
-rw-r--r--    1 root     root         2345 Oct 20 10:00 passwd
-rwxr-xr-x    1 root     root      1234567 Oct 15 14:30 gcc
drwxrwxrwt   15 root     root          4096 Oct 20 12:00 tmp
crw-rw-rw-    1 root     root             1 Oct 20 09:00 null

Обратить внимание:
• У каталога `/tmp` первый символ `d`.
• У обычного файла `-`.
• Размеры выровнены по правому краю.
• Имена владельцев и групп выровнены по левому краю.
