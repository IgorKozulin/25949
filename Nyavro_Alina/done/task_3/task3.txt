# 3: Установка идентификатора пользователя (setuid)

## 1. Подготовка рабочего места
Переходим в директорию задания и создаем новую папку:

cd ~/MyOSTest
mkdir task_3
cd task_3

## 2. Ключевые концепции для понимания задачи

• Реальный UID (getuid): ID пользователя, который вошел в систему.
• Эффективный UID (geteuid): ID, от имени которого процесс реально работает (проверяет права доступа к файлам).
• Бит setuid (u+s или 4xxx): Специальный бит прав. Если он установлен на исполняемом файле, то при запуске программы эффективный UID процесса становится равным UID владельца этого файла, а не того, кто его запустил.
• setuid(uid): Системный вызов для смены эффективного UID. Вызов setuid(getuid()) сбрасывает привилегии, возвращая эффективный UID к значению реального пользователя.

## 3. Шпаргалка: Права доступа (chmod / ls -l)

ФОРМАТ ПРАВ:
-rw-------
│└┬┘└┬┘└┬┘
│ │  │  └ остальные (others)
│ │  └─── группа (group)
│ └────── владелец (owner)
└──────── тип файла (- файл, d каталог)

ЗНАЧЕНИЯ БИТОВ:
r = 4 (чтение)
w = 2 (запись)
x = 1 (выполнение/вход в каталог)

СПЕЦИАЛЬНЫЕ БИТЫ:
4xxx  setuid   (s в позиции владельца x) — запуск от имени владельца файла.
2xxx  setgid   (s в позиции группы x)
1xxx  sticky   (t в позиции остальных x)

Пример установки setuid:
chmod u+s имя_файла
# или числами:
chmod 4755 имя_файла

ВАЖНО: Чтобы программа с setuid сработала, она должна принадлежать пользователю, чьи права вы хотите получить (в данном случае — вам), и иметь бит выполнения (x).

## 4. Основные библиотеки

#include <stdio.h>        // printf, perror
#include <stdlib.h>       // exit, EXIT_FAILURE
#include <unistd.h>       // getuid(), geteuid(), setuid()
#include <sys/types.h>    // типы данных для UID

## 5. Алгоритм решения

1. Подготовка тестового файла:
   - Создайте файл data.txt с любым содержимым.
   - Установите права 600 (chmod 600 data.txt), чтобы доступ был только у владельца.

2. Вывод идентификаторов:
   - Напишите функцию, которая выводит Real UID (getuid) и Effective UID (geteuid).

3. Проверка доступа до смены прав:
   - Попробуйте открыть файл data.txt через fopen().
   - Запрограммируйте вывод сообщения об успехе или ошибке (perror).

4. Сброс привилегий:
   - Вызовите setuid(getuid()). Это сделает эффективный UID равным реальному.

5. Повторная проверка:
   - Снова выведите UID'ы.
   - Снова попробуйте открыть файл data.txt.

## 6. Сборка и тестирование

Создайте Makefile для сборки setuid_test.c:

CC = gcc
CFLAGS = -O2
TARGET = setuid_test
SRC = setuid_test.c

all: $(TARGET)

$(TARGET): $(SRC)
	$(CC) $(CFLAGS) -o $(TARGET) $(SRC)

clean:
	rm -f $(TARGET)

.PHONY: all clean

Команды для запуска:
make clean
make

## 7. Порядок проверки работы setuid

1. Запустите программу от своего имени. Убедитесь, что файл открывается оба раза.
2. Найдите одногруппника на сервере.
3. Дайте ему права на выполнение вашей программы: chmod 755 setuid_test
4. Попросите его запустить ./setuid_test. Он должен получить ошибку доступа ко второму файлу, так как права на data.txt стоят 600.
5. Установите бит setuid на программу: chmod u+s setuid_test
6. Попросите одногруппника запустить программу снова. 
   - Теперь он должен увидеть, что Effective UID стал вашим.
   - Первый попытка открытия файла должна быть успешной.
   - После вызова setuid(getuid()) привилегии сбросятся, и вторая попытка откроет файл с ошибкой.
