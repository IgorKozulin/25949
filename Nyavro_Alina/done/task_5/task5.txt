5. 	Таблица поиска строк в текстовом файле.
Написать программу, которая анализирует текстовый файл, созданный текстовым редактором, таким как ed(1) или vi(1). После запроса, который предлагает ввести номер строки, с использованием printf(3) программа печатает соответствующую строку текста. Ввод нулевого номера завершает работу программы. Используйте open(2), read(2), lseek(2) и close(2) для ввода/вывода. Постройте таблицу отступов в файле и длин строк для каждой строки файла. Как только эта таблица построена, позиционируйтесь на начало заданной строки и прочтите точную длину строки. 
Подсказка: Выберите или создайте текстовый файл с короткими строками. Помните, что первая строка начинается с нулевого отступа в файле. Найдите каждый символ перевода строки, запишите его позицию; в программе следует использовать вызов lseek(fd, 0L, 1). Для отладки распечатайте эту таблицу и сравните с таблицей, полученной вручную. Как только таблицы начнут совпадать, можно приступать к запросу номера строки.

# 5: Таблица поиска строк (Line Lookup Table)

## 1. Подготовка рабочего места

# Сохраняем: Ctrl+O, Enter, выход: Ctrl+X

## 2. Ключевые концепции для понимания задачи

• Системные вызовы (Low-level I/O): В отличие от stdio (fopen/fgets), функции open/read/lseek работают напрямую с файлом как с потоком байтов. Они не буферизируют данные и не добавляют завершающий ноль '\0'.
• Индексация файла: Вместо чтения всего файла в память, мы строим "карту" (таблицу), где для каждой строки храним её смещение (offset) от начала файла и длину (length).
• Random Access: Благодаря таблице, чтобы прочитать N-ю строку, нам не нужно перебирать предыдущие. Мы делаем lseek к нужному offset и read ровно length байт.
• Динамическое расширение: Так как количество строк неизвестно, используем realloc для увеличения массива структур по мере чтения файла.

## 3. Шпаргалка: Системные вызовы ввода-вывода

ФУНКЦИИ (unistd.h, fcntl.h)
• int open(const char *pathname, int flags): Открывает файл. Возвращает файловый дескриптор (int) или -1. Флаги: O_RDONLY (чтение).
• ssize_t read(int fd, void *buf, size_t count): Читает до count байт. Возвращает количество прочитанных байт, 0 (EOF) или -1 (ошибка).
• off_t lseek(int fd, off_t offset, int whence): Меняет позицию чтения. 
  - SEEK_SET: от начала файла.
  - SEEK_CUR: от текущей позиции.
  - Подсказка: lseek(fd, 0, SEEK_CUR) возвращает текущую позицию без смещения.
• int close(int fd): Закрывает файловый дескриптор.

СТРУКТУРА ДАННЫХ
typedef struct {
    long offset;   // Позиция начала строки в файле (байт от начала)
    int length;    // Длина строки (количество символов)
} LineInfo;

ВАЖНО
• Символ перевода строки '\n' (ASCII 10) является разделителем.
• read не добавляет '\0'. Если вы хотите вывести строку через printf, нужно вручную добавить нулевой байт в конец буфера.
• Нумерация строк для пользователя обычно начинается с 1, а индексы массива — с 0.

## 5. Алгоритм решения

1. Открытие файла:
   - Используйте open(argv[1], O_RDONLY). Проверьте результат на ошибку (-1).

2. Построение таблицы (первый проход по файлу):
   - Инициализируйте пустой массив LineInfo и счетчики (num_lines, capacity).
   - Читайте файл побайтно (или блоками) в цикле while(read(...)).
   - Отслеживайте текущую позицию (current_pos) и начало текущей строки (line_start).
   - При встрече символа '\n':
     - Запишите в таблицу: offset = line_start, length = текущая длина.
     - Увеличьте num_lines. При необходимости расширьте массив через realloc.
     - Сбросьте line_start и длину для следующей строки.
   - После цикла проверьте, осталась ли последняя строка без '\n', и добавьте её в таблицу.

3. Отладочный вывод:
   - Выведите содержимое построенной таблицы (Offset и Length для каждой строки), чтобы убедиться в корректности данных.

4. Интерактивный запрос (второй этап):
   - В цикле запрашивайте у пользователя номер строки.
   - Если введен 0, завершите программу.
   - Проверьте номер на выход за границы (1..num_lines).
   - Получите offset и length из таблицы для выбранного номера (индекс = номер - 1).

5. Чтение и вывод конкретной строки:
   - Используйте lseek(fd, offset, SEEK_SET) для перехода к началу строки.
   - Выделите буфер размером length + 1.
   - Прочитайте ровно length байт через read.
   - Добавьте '\0' в конец буфера.
   - Выведите строку через printf.
   - Освободите буфер.

6. Очистка ресурсов:
   - Закройте файл (close) и освободите память таблицы (free) перед выходом.
