## 2. Ключевые концепции для понимания задачи

• Асинхронные события: Программа должна делать две вещи одновременно: ждать ввода пользователя и следить за временем. В Unix это решается через сигналы.
• SIGALRM: Специальный сигнал, который генерируется системным вызовом alarm().
• Обработчик сигнала (Handler): Функция, которая выполняется "вне очереди", когда приходит сигнал. В нашем случае она должна вывести весь файл и завершить программу.
• Сброс таймера: После того как пользователь успел ввести число, таймер нужно отключить (alarm(0)), иначе он может сработать в неподходящий момент.

## 3. Шпаргалка: Сигналы и таймеры в Unix

ФУНКЦИИ (signal.h, unistd.h)
• void (*signal(int sig, void (*func)(int)))(int): Устанавливает обработчик для сигнала sig. func — указатель на функцию-обработчик.
• int alarm(unsigned int seconds): Запланировать отправку сигнала SIGALRM процессу через seconds секунд. Возвращает остаток времени предыдущего будильника.
• alarm(0): Отменяет любой ранее установленный будильник.
• void _exit(int status): Немедленно завершает процесс. Используется внутри обработчиков сигналов вместо exit(), так как не вызывает функции очистки stdio (что безопасно при асинхронном прерывании).

ГЛОБАЛЬНЫЕ ПЕРЕМЕННЫЕ
Обработчики сигналов работают асинхронно и имеют фиксированную сигнатуру. Чтобы получить доступ к файловому дескриптору или имени файла внутри обработчика, их необходимо объявить как глобальные или статические переменные.

ВАЖНО
• signal(SIGALRM, handler): Регистрирует функцию, которая вызовется при истечении времени.
• fflush(stdout): Перед блокирующим вызовом ввода (scanf) обязательно сбрасывайте буфер вывода, чтобы пользователь увидел приглашение.

## 5. Алгоритм решения

1. Глобальные данные:
   - Объявите глобальные переменные для хранения имени файла и файлового дескриптора, чтобы обработчик сигнала мог к ним обратиться.

2. Построение таблицы (как в задании 5):
   - Откройте файл, прочитайте его побайтно/блоками и заполните массив структур LineInfo (offset, length).
   - Выведите отладочную таблицу.

3. Установка обработчика:
   - Напишите функцию alarm_handler, которая:
     - Открывает файл заново (или использует глобальный дескриптор).
     - Читает и выводит всё содержимое файла через write(STDOUT_FILENO, ...).
     - Завершает процесс через _exit(EXIT_SUCCESS).
   - Зарегистрируйте её: signal(SIGALRM, alarm_handler).

4. Интерактивный цикл с таймером:
   - В цикле while(1):
     - Выведите приглашение и сделайте fflush(stdout).
     - Запустите таймер: alarm(5).
     - Ожидайте ввод номера строки через scanf.
     - Если ввод успешен: немедленно остановите таймер alarm(0).
     - Если ввод не удался (не число): очистите буфер, сбросьте таймер и продолжите цикл.
     - Если введен 0: выйдите из цикла.
     - Если номер корректен: используйте lseek и read для вывода конкретной строки (как в задании 5).

5. Завершение работы:
   - Закройте файл и освободите память таблицы перед выходом из main.

## 6. Сборка и тестирование

Создайте Makefile для сборки line_lookup_alarm.c:

CC = gcc
CFLAGS = -O2
TARGET = line_lookup_alarm
SRC = line_lookup_alarm.c

all: $(TARGET)

$(TARGET): $(SRC)
	$(CC) $(CFLAGS) -o $(TARGET) $(SRC)

clean:
	rm -f $(TARGET)

.PHONY: all clean

Команды для запуска:
make clean
make
./line_lookup_alarm test.txt
