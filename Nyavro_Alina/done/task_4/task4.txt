# 4: Список строк
Напишите программу, которая вставляет строки, введенные с клавиатуры, в список. Память под узлы списка выделяйте динамически с использованием malloc(3). Ввод завершается, когда в начале строки вводится точка (.). Затем все строки из списка выводятся на экран.
Подсказка: Объявите массив символов размера, достаточного чтобы вместить самую длинную введенную строку. Используйте fgets(3), чтобы прочитать строку, и strlen(3), чтобы определить ее длину. Помните, что strlen(3) не считает нулевой символ, завершающий строку. После определения длины строки, выделите блок памяти нужного размера и внесите новый указатель в список. При сдаче этой программы на С++ запрещается использовать std::string и контейнеры STL для реализации списка.  Я понимаю, что это практически лишает смысла использование C++ в этой задаче.

# 4: Список строк (Управление памятью)

## 1. Подготовка рабочего места
Переходим в директорию задания и создаем новую папку:

cd ~/MyOSTest
mkdir task_4
cd task_4

## 2. Ключевые концепции для понимания

• Связный список (Linked List): Линейная структура данных, где элементы (узлы) хранятся в разных участках памяти и связаны указателями. Последний узел указывает на NULL.
• Динамическое выделение памяти: Использование malloc() для создания узлов списка "на лету", так как количество строк заранее неизвестно.
• Указатель на указатель (Node **head): Используется в функциях изменения списка, чтобы менять саму голову списка, если она была NULL.
• Управление жизненным циклом: Создание -> Заполнение -> Вывод -> Полное освобождение памяти. В C нет сборщика мусора, всё выделенное через malloc нужно освобождать через free.

## 3. Шпаргалка: Работа со строками и памятью в C

ФУНКЦИИ ПАМЯТИ (stdlib.h)
• void *malloc(size_t size): Выделяет блок памяти размера size байт. Возвращает указатель или NULL при ошибке. Память не инициализируется.
• void free(void *ptr): Освобождает ранее выделенную память. После вызова указатель становится "висячим".
• void *realloc(void *ptr, size_t size): Изменяет размер ранее выделенного блока. Может переместить данные.

ФУНКЦИИ СТРОК (string.h)
• size_t strlen(const char *s): Возвращает длину строки БЕЗ учета завершающего нуля '\0'.
• char *strcpy(char *dest, const char *src): Копирует строку src в dest (включая '\0'). dest должен иметь достаточно места!
• char *strdup(const char *s): (POSIX) Эквивалент malloc(strlen(s)+1) + strcpy. Выделяет память и копирует строку. Требует free().

ВВОД/ВЫВОД (stdio.h)
• char *fgets(char *s, int size, FILE *stream): Читает строку из поxтока. Останавливается при '\n', EOF или прочтении size-1 символов. Всегда добавляет '\0'. Сохраняет '\n' в буфере, если он поместился.

СТРУКТУРА УЗЛА
struct Node {
    char *data;        // Указатель на динамическую строку
    struct Node *next; // Указатель на следующий узел
};

ВАЖНО
• sizeof(char) всегда равен 1, поэтому для строки длины N нужно N+1 байт.
• fgets безопаснее gets, так как ограничивает длину ввода.
• Нельзя присваивать new_node->data = buffer. Буфер перезаписывается при каждом новом вводе. Нужно создавать независимую копию строки в куче.

## 4. Основные библиотеки

## 5. Алгоритм решения

1. Описание структуры узла:
   - Создайте struct Node, содержащий char *data (указатель на строку) и struct Node *next.

2. Функция добавления (append):
   - Принимает указатель на голову списка (Node **head) и строку.
   - Выделяет память под сам узел (malloc(sizeof(Node))).
   - Выделяет память под строку (malloc(strlen(str) + 1)) и копирует данные.
   - Если список пуст (*head == NULL), делает новый узел головой.
   - Иначе находит последний элемент и присоединяет новый узел к нему.

3. Функция освобождения памяти (free_list):
   - Проходит по всему списку.
   - Для каждого узла сначала освобождает память под строку (free(node->data)), затем под сам узел (free(node)).

4. Основная логика (main):
   - Объявите буфер char buffer[1024] для ввода.
   - В цикле while(1) используйте fgets для чтения ввода.
   - Удалите символ новой строки '\n' из конца буфера, если он есть.
   - Проверьте первый символ: если это '.', прервите цикл (break).
   - Если строка не пустая, вызовите append.

5. Вывод результатов:
   - Пройдитесь по списку от head до NULL и выведите data каждого узла.
   - Вызовите free_list(head) перед завершением программы.

## 6. Сборка и тестирование

Создайте Makefile для сборки list_strings.c:

CC = gcc
CFLAGS = -O2
TARGET = list_strings
SRC = list_strings.c

all: $(TARGET)

$(TARGET): $(SRC)
	$(CC) $(CFLAGS) -o $(TARGET) $(SRC)

clean:
	rm -f $(TARGET)

.PHONY: all clean

Команды для запуска:
make clean
make
./list_strings
